# CGPA Calculator

A simple **C++-based CGPA Calculator** that calculates the semester GPA/CGPA based on the grades and credit hours of different courses.

## 📌 Features

* Takes the number of courses as input.

* Accepts course name, grade point, and credit hours.

* Calculates grade points using:

  **Grade Points = Grade × Credit Hours**

* Calculates total credits.

* Calculates total grade points.

* Calculates semester GPA.

* Displays individual course details.

* Displays the final CGPA.

## 🛠️ Technologies Used

* **C++**
* **Vectors**
* **Loops**
* **Basic arithmetic operations**
* **User input/output**

## 🧮 Formula

The GPA/CGPA is calculated using:

```text
GPA = Total Grade Points / Total Credits
```

Where:

```text
Total Grade Points = Σ(Grade × Credit Hours)
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `.cpp` file in a C++ IDE or compiler.
3. Compile the program.
4. Run the program.
5. Enter the required course details.
